# Garage Flow

Elaborar um sistema completo para controle de Oficinas Mecânicas, Martelinho de Ouro, Lojas de Estética de Veículos, dentre outros dentro de ramo de atividade semelhantes. Necessidade de gravar base de dados no supabase. Gerar os códigos sql necessários para que tudo fique salvo no supabase. O site será publicado online, onde será informado o link depois. Necessário ter login criptografado, com diversos níveis de perfis de usuários, Admin, Financeiro, Auditoria e outros que julgar necessário. Ter um perfil para cadastrar o Cliente e esse poder acompanhar a ordem de serviço, visualizando todo trabalho que está sendo executado na respectiva ordem de serviço, a qual terá um protocolo e uma senha geradas automaticamente par que cliente possa acessar online. Ter integração com whatsapp afim de enviar status do serviço, sendo cada mudança de status possível enviar situação para o cliente, onde comunicará automaticamente da melhor forma que está sendo praticada na atualidade. Ter opção de configuração para que ao abrir uma nova ordem de serviço possa ser Digitado todas as informações ou FALADO, por exemplo, responsável fala: Meu assistente, abrir uma ordem de serviço, cadastrar o cliente Jucemar De Giacometti, no telefone 54996161740, colocar o serviço de martelinho de ouro no paralama dianteiro esquerdo no valor de R$300,00 e pintura do parachoque traseiro no lado direito no valor de R$120,00. Assim que o responsável falar o sistema irá realizar todos os passos soliticados, Abrindo uma Ordem de Serviço, Cadastrando o Cliente com os dados informados, e lançando os serviços e valores, bem como, pode lançar produtos e valores. E Mais instruções poderiam ser dadas, como: Enviar orçamento pelo whatapp, ou qualquer outra instrução. Conforme o ramo de atividade moldar o formato adequado de orçamento, campos e tudo mais. Opção de tirar diversas fotos, sempre com a instrução DIGITADA  ou POR VOZ. Essas fotos ter opção do Antes, Durante e Depois. Tudo fica gravado na base de dados do supabase, para acesso a qualquer tempo. Muito importante ter a placa do veículo, onde traz todas as informações de serviços prestados, independente do cliente, pois o carro pode ser vendido de uma pessoa para outra. Ter opção para o cliente acessar um link com o protocolo e senha gerada automaticamente e acompanhar toda ordem de serviço, somente visualizar. Ter relatórios e gráficos de tudo que é tipo, confrontando tudo de forma gerencial.
